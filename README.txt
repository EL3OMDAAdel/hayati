# حياتي
تطبيق شخصي عربي لتسجيل أمور الحياة اليومية.

## التشغيل
- ارفع جميع الملفات كما هي إلى مستودع GitHub مستقل.
- فعّل GitHub Pages من الفرع main والمجلد /(root).
- افتح رابط الموقع من Chrome على الهاتف، ثم اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».
- افتح التطبيق مرة واحدة مع الإنترنت حتى يتم تخزين ملفات التشغيل، وبعد ذلك يعمل دون اتصال.
- البيانات تحفظ محليًا في متصفح/تطبيق هذا الجهاز ولا ترفع إلى أي خادم.

## تنبيه مهم
مسح بيانات المتصفح أو حذف التطبيق قد يؤدي إلى فقد البيانات. استخدم «تصدير نسخة احتياطية» من داخل التطبيق واحفظ ملف JSON في مكان آمن.
